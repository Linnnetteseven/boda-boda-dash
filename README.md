# Boda Boda Dash

A browser game set on a Nairobi road. Ride a boda boda, dodge potholes and matatus, and pick up waving passengers for Ksh 50 each.

Live: https://boda-boda-dash.vercel.app

## Versions

Each version has its own branch and tag.

| Branch / tag | What it is |
|---|---|
| `v1` | Top-down 2D canvas runner. |
| `v2` | First 3D runner: Three.js, behind-the-rider camera, three lanes, pause button. |
| `v3` | One self-contained `index.html`: Nairobi city street, detailed rider and boda, five power-ups, main menu, synthesized music and sound effects. |
| `main` | Latest work. |

## Run it locally

Open `index.html` through any static server, for example:

```bash
npx serve .
```

## Controls

- Laptop: ← → or A / D to switch lanes, P or Esc to pause, Enter to start.
- Phone: tap the left or right side of the screen.
